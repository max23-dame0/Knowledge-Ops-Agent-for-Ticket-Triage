# 发票申请处理说明

## 适用场景
客户申请开具发票、补开发票、更正抬头、查询发票发送状态或索取历史账单凭证时，可使用本说明。适用于标准线上订单，不适用于线下合同与第三方渠道采购。

## 处理步骤
1. 先确认订单编号、付款时间、付款主体和当前开票状态，避免对未支付订单创建发票请求。
2. 若为首次开票，收集开票抬头、税号、邮箱和所需开票明细；信息不完整时退回补充。
3. 标准电子发票通常在付款确认后 3 个工作日内开具，并发送到登记邮箱。
4. 如客户需要补开发票，先确认原订单是否已开票；同一订单原则上只保留一份有效发票记录。
5. 发票更正一般仅限抬头或邮箱类非关键字段，且需在当期账务关闭前提交。

## 升级条件与例外
- 涉及跨月更正、税务合规疑问或红字发票申请时，升级到财务运营组。
- 订单来自代理商或合作伙伴渠道时，不由平台直接开票，应引导客户联系原销售渠道。
- 一线支持不得手工修改已归档的税务记录。
